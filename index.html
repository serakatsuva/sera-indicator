Télécharger l’EA MT5
  1. Dans MT5 : Fichier → Ouvrir le dossier des données → MQL5 → Experts.
  2. Copiez le fichier téléchargé, compilez-le dans MetaEditor, puis attachez-le à un graphique.
  3. Autorisez WebRequest vers https://serakatsuva.github.io et activez Algo Trading.
  4. Laissez AllowRealAccount = false pendant les tests sur compte Démo.

Important : le site ne reçoit jamais votre mot de passe MT5. L’EA utilise uniquement le compte déjà connecté dans votre terminal.
